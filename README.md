# Gestione Ambulatorio Medico
## Descrizione
Il progetto consiste nella progettazione di un database relazionale per la gestione di un ambulatorio medico e nella realizzazione di un modello di Data Warehouse per l'analisi dei dati.

## Obiettivi
* Progettare il database relazionale.
* Definire le tabelle e le relazioni tra le entità.
* Popolare il database con dati sintetici.
* Realizzare query SQL per interrogare e gestire i dati.
* Progettare un modello dimensionale per il Data Warehouse.
* Analizzare i dati attraverso tabelle e grafici.
  
## Tecnologie utilizzate
* MySQL Workbench
* Draw.io
* Excel
  
## Struttura del progetto
* `database/`: script SQL per la creazione e il popolamento del database.
* `data-warehouse/`: query, dati e documentazione relativi al Data Warehouse.
* `diagrammi/`: diagrammi del database e dello schema dimensionale.
* `documentazione/`: documentazione tecnica e modelli.
* `presentazione/`: presentazione del progetto.

## Database
Il database comprende entità relative a pazienti, personale sanitario, appuntamenti, cartelle cliniche, visite, prescrizioni, esami, terapie, allergie e vaccinazioni.

## Data Warehouse
Il progetto comprende una fact table e un modello dimensionale destinati all'analisi dei dati dell'ambulatorio.

## Dati
I dataset sono dichiarati come sintetici e destinati a finalità didattiche.

## Installazione
1. Installare MySQL.
2. Aprire MySQL Workbench o un client compatibile.
3. Eseguire lo script di creazione del database.
4. Eseguire gli script di popolamento delle tabelle nell'ordine previsto dalle dipendenze.
5. Eseguire le query contenute nei file SQL.

Prima dell'esecuzione, verificare che gli script siano compatibili con la versione di MySQL utilizzata.
